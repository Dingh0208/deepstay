# 附件上传、引用与费用

DeepSeek 官方连接通过 Anthropic 兼容 Files API 上传附件，再在消息中引用返回的 `file_id`。Word、PDF、PPT 默认选择 `text_recognition`；需要文档中的图片和图表时，可在上传确认框选择 `rich_layout_recognition`。普通文本、代码、表格和电子书沿用 `user_data`。请求表单先写 purpose，再写 file。官方服务支持的模型都显示附件入口；文件与联网搜索工具能力分开判断。

第三方 OpenAI-compatible 与 Anthropic-compatible 连接使用同一附件入口，不调用 DeepSeek Files API。图片先在本机按现有尺寸规则处理，再以 OpenAI `image_url` 数据 URL 或 Anthropic base64 图片块发送；PDF、DOCX、DOC 和文本附件在本机提取文字，随当前消息作为文本发送。提取结果保存在本机附件记录中，后续续聊复用，不会每轮重复解析同一文件，也不会把 DeepSeek `file_id` 发给第三方。DeepSeek 官方 PDF/Word 收费解析确认只用于官方 Files API；第三方不弹收费解析选项。

Word / PDF 的字节大小不能代表模型展开后的上下文长度。官方返回文件 ID 前已执行解析；聊天报错不代表上传失败。上传解析成功可能按页计费，历史文件的全文在后续请求中仍计入模型输入 Token。复用文件 ID 只避免再次上传解析，不代表以后免费读取。客户端中断时，服务端仍可能完成解析并计费，不能靠自动重传来判断第一次是否成功。

选择收费解析文档后先确认解析方式，取消不上传，连续点击确认只提交一批。后续聊天复用已经保存的 ID；同一请求中的同一个文档只保留最近一次引用，避免重复输入，也避免裁剪旧轮次时移除本轮附件。图片引用不按此规则省略。

消息中的非图片文件提供「暂停引用 / 恢复引用」。暂停只作用于当前会话内同一本地文件的所有引用，不补传、也不发送 document 块；原件、历史回答和已有摘要保留。恢复复用原 ID。该状态保存在本机数据库，历史 ZIP 沿用官方格式，不保存此设置及非图片原件。

文档 ID 失效或只剩本地原件时，不自动重新付费解析；提示用户重新选择文件并确认，或暂停该文件继续。本轮文档超出接口上下文时直接说明文件与消息合计过长，避免带同一份全文自动重复尝试。历史过长仍保留既有的有界裁剪逻辑，不改写本地历史。

图片所有入口共用预处理，发送副本最长边限制为 4096，保留本地原件。只有编码头证明原始尺寸安全时才原样发送；低内存解码器可能返回缩小的尺寸，此时仍重新编码，避免把超过 8192 像素的原始图片传给接口。明确定位的旧图尺寸错误每次发送最多自动修复一次，持续拒绝后停止。

服务端未提供文档展开 Token 时，界面只能使用本地估算，不能由文件体积编造精确费用。原始文本、图片和会话不会为了测试发送到公共服务；回归使用合成文件与模拟响应。

依据：[DeepSeek Files API](https://api-docs.deepseek.com/zh-cn/guides/files_api/)、[文件解析](https://api-docs.deepseek.com/zh-cn/guides/document_parsing/)。DSH 与 DSH Go 的架构及可借鉴行为见 [对照文档](DSH_GO_COMPARISON.md)；它们的本机工具文件读取不能等同于本项目的云端文档解析。
