## 实现与回归

- 人物库保留原 `greeting` 和可选 `alternateGreetings`，不迁移或清空旧库。JSON/PNG/CHARX，V1/V2/V3 的首开场与候选顺序、空项、宏替换均保留；原生 version1 JSON 导出往返保留全部候选。
- 选择开场前可预览；新会话只保存选中一个开场，其他候选不进入快照、提示或上下文预算。空开场不创建助手消息；越界索引不新建会话。修改/删除模板保持旧快照，删除开场消息移除当前会话隐藏开场语境；历史 ZIP 保持原单开场快照结构。
- 候选最多 100 个、单条 10,000 字符、合计 100,000 字符；保存前同时验证便携 JSON 不超过 200KiB。测试先复现超限保存成功却不可导出的问题，修复后超限新建/更新均拒绝，保留草稿和原模板；精确 200KiB 可往返，增加一字节拒绝。非法类型与超大载体不截断。
- 开场选择弹窗使用现有滚动区域，避免短屏把确认按钮挤出；取消导入、取消选择不新增模板或会话。
