# v0.1.12 附件与搜索验收

基线为 v0.1.11 后的 main `41ceb5cd6317aad323d37110371c9f8c5ec99af7`。本轮处理文字 Word / PDF 解析、文件引用费用、长图尺寸和错误重试，并按用户指定的 DSH Go 源码核查已有功能。发布版本为 0.1.12，Android versionCode 13。

## 行为与回归

| 项目 | 修改与证据 |
| --- | --- |
| Word / PDF / PPT 解析 | 上传前整批校验并确认，默认文字解析，可主动选图文解析。取消不调用上传，快速双击确认只提交一批。草稿重试和持久化保留解析方式，purpose 位于 file 之前。网页实际 DOCX、PDF 多选已验证。 |
| 后续文件费用 | 正常续聊复用 file_id，没有重复上传。官方每轮引用全文仍计输入 Token，不能承诺一次上传后免费。消息文件卡可暂停/恢复引用；暂停不补传、不发送 document，原件与已生成消息保留。网页模拟多轮、暂停、恢复复用 ID、刷新持久化已验证。 |
| 重复引用与裁剪 | 单请求相同文档 ID 只保留最近引用，当前提问优先；裁掉旧轮次仍保留本轮附件。不会去重图片。实际请求序列化与 fitRequestHistory 联合回归通过。 |
| 失效和未知解析 | 失效的收费文档不清 ID 后静默重传；只有本地原件也不自动付费解析，明确提示重新选择确认或暂停引用。当前文档超限不自动重复带全文发送，保留文件和记录并提示拆分。 |
| 长截图 | 修复解码器降采样导致原始超限图片被透传、Android 通用 MIME 绕过缩图的问题。真实浏览器 PNG/JPEG 1000×12000 经 ImageBitmap 和 Image 回退均得到 341×4096；原件仍为 1000×12000，500×600 正常图原样保留。 |
| 尺寸错误 | HTTP 200 JSON 的精确图片尺寸错误也进入修复路径。持续拒绝时同一本地图片只重传一次；实际 store 回归验证 2 次聊天、1 次修复上传，原件保留；不触发上下文压缩。 |
| DSH Go 搜索借鉴 | 独立实现全半角与大小写折叠、同条消息内多词 AND。保留全部会话、隐藏分支及时间排序，原文片段不截断表情。测试覆盖 110+ 会话、中文多词、全角、İ 大小写长度变化及取消。实际网页“美食库　推荐”返回两条相应消息，顺序正确。 |

新增费用与文件引用回归执行真实草稿、上传队列、store、请求转换、错误分类及 IndexedDB 模块；网络为合成响应。暂停/恢复另有本机持久化、同会话多引用、跨会话隔离和生成/导入忙碌保护测试。没有向模型发送真实用户文档、聊天或调用收费接口。
