# 0.1.14：DSH Go 逻辑适配第一批

本批对应 [P01–P03](DSH_GO_PORTING_PLAN.md)：更新目标完整性、按接口/协议/模型保存上下文容量、最近文字草稿恢复。界面沿用原设计。参考行为独立实现，没有引入 DSH Host 或复制 AGPL 核心代码。

## 已验证的行为

- 更新：实际 Android PackageManager 与 Capacitor bridge 拒绝同 versionCode、错误目标 versionName、错误目标 code、错误 SHA 和缺失目标身份；合法同签名 code16 测试候选从已安装 code15 打开系统安装器，取消后仍为 code15。恢复待安装包会重新验 hash、版本、包名和签名。清单中较新版本或不同 hash 能替换过时缓存，网络失败保留有效新版安装入口，安装失败可重新下载。
- 容量：OpenAI 与 DeepSeek 路由规范化、同名模型跨接口隔离、Key 轮换不改容量、旧全局设置迁移、清空单一路由、重启恢复及实际请求预算回归通过。存储额度不足时保留旧设置，后续启动可重试迁移。
- 草稿：最近 30 条文字草稿防抖保存，后台或 pagehide 及时写入；发送、删除、清空后不会被旧定时器写回。删除后重导同 ID 仍可输入。附件不落入草稿持久化，也不自动恢复上传。总文字持久化限制 500,000 字符，超限不截断活动输入。

## 实际网页与 Android

网页使用 0.1.14 生产构建，在独立测试来源验证刷新恢复文字、模型 A/B 默认及独立容量、往返切换。Ego 的数字框自动滚轮及填充会改变测试值，最终以原生 input setter 分发输入事件，再用现有保存与模型切换按钮，核对保存值及重启结果；Android 另行验证真实 WebView 表单。

Android 11 / WebView 83，隔离包 `xyz.infralyx.deepstay.attachmentqa`：从 0.1.13/code14 覆盖到 0.1.14/code15，DB14 中 2 个合成会话、13 条消息、3 个原始附件与 2 个人物预设哈希均保持一致，393px 无横向溢出。实际设置表单分别保存 65,536 与 131,072 窗口，模型切换和强制停止冷启动后保持隔离；新会话与原会话文字草稿完整恢复。

系统合法覆盖升级也显示“已安装此应用，是否更新”，该提示本身不能证明包过旧；本批检查真实 APK 元数据，并拒绝应用内同版更新。外部重复打开旧下载文件由 Android 自身处理。
