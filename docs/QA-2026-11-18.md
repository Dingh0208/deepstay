## 自动回归

Node.js 24+，执行 `pnpm test`；15 个脚本覆盖 API 配置、切换服务、余额、流式渲染、手机输入、背景、聊天搜索、压缩、导入及更新。另执行 `pnpm type`、`pnpm lint` 和 `git diff --check`。回归证据 JSON 和生成 ZIP 在 tests 中，已加入忽略规则；测试使用合成数据和模拟网络。

- 压缩：长对话分批摘要、固定记忆、结构化关系/时间线/承诺/更正提示、缓存复用、修改历史/分支/服务后失效、取消、失败及超预算不发送。增加真实 store 发送链路，验证仅携带当前会话的记忆、摘要和近期完整轮次，同时保留全部原文。合成返回值不代表真实模型的语义召回质量。
- 新增导入：保留原有会话和准备期间新消息、重复导入的会话及附件 ID 隔离、失败回滚、取消、非法 CRC、延迟读取后再完成，以及清空历史仍生效。包含 83,888,098 字节 ZIP，其中单个合成图片 Blob 为 83,886,080 字节。

## 实际 Web 验收

本地开发入口端口 8090，桌面与 390px / 320px 页面均已检查。

- 官方接口地址禁用，余额按钮位于拉取模型旁。
- 上下文压缩按最终确认横向一行展示：左侧标题、说明和当前会话名称，右侧开关与记忆按钮同一行。桌面、390px 和 320px 均无横向溢出。聊天背景的标题、描述和操作控件纵向左对齐，上传后仍无设置内图片预览，选择与恢复默认可用。位置信息已移除。
- 80 MiB ZIP 后台读取与提交成功；重复导入得到两个独立会话和两个完整图片 Blob。测试图为 PNG 文件头加填充数据，验证归档与存储容量，不验证真实图片解码。
- 两个会话分别编辑不同角色、称呼和约定，切换后各自记忆保持；IndexedDB 中分别保存，重复导入不覆盖旧记忆。
- 开发热更新曾导致旧哈希 Worker 地址失效；开发模式 JS 改为稳定文件名，正式构建保留哈希。
