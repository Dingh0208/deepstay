## DSH Go 对照与实现

对照固定提交 `971b0d895f16035e356315b8af08fa3a12afe87c`，区分普通 Host 与直接请求模型的酒馆引擎。人物卡、入口及开场行为作为参考，独立实现。DeepStay 为每个会话冻结人物快照，修改或删除人物库保留旧聊天，与 DSH Go 后续读取最新卡及删除人物级联删除聊天的行为不同。具体见 [机制对照](DSH_GO_COMPARISON.md)、[功能清单](DSH_GO_FEATURES.md)和[人物功能说明](CHARACTERS.md)。

## 最终两轮

修复 Android 人物导出和删除开场语境后，最终完整 `pnpm test` 两轮均通过 **40 套**。本机日志：`D:\codex_documents\deepstay-character-qa-20261120\full-regression-final-limited-round-1.log` 与 `full-regression-final-limited-round-2.log`。类型检查、lint 零警告和 `git diff --check` 通过。生产构建、Capacitor 同步、Android `:app:testDebugUnitTest` 与 release 构建通过。

早期两轮各 39 套通过后，独立审查新增了两处修复及 UI 导出回归，因此以最终 40 套为准。期间一次 Windows 测试进程无断言异常退出、两次 Gradle 因本机 native 内存分配失败中断；错开构建和测试，并限制 Node 堆为 768 MiB、Gradle 使用 512 MiB SerialGC 后完成上述最终结果。

## 网页与 Android

网页使用独立来源 `http://deepstay-character-qa.localhost:8090/`、合成人物及模拟网络，未操作用户原来源。实际验证创建、编辑后新旧会话不同设定、删除保留聊天、卡预览取消、导出往返、刷新保留、设置入口和窄屏无溢出。证据包括 `browser-character-isolation.json`、`browser-character-persistence.json`、`browser-card-formats.json` 与截图。完成后移除模拟 Key 和模拟接口地址，保留预览页。

Android 使用 emulator-5570 上独立包 `xyz.infralyx.deepstay.attachmentqa`，Android 11 / WebView 83。覆盖安装升级 DB13 → DB14，既有 1 会话、10 消息、3 原件及文件 ID、暂停引用状态逐项保留；正式包、其他 QA 包未清除。人物创建、角色卡文字预览保存、发送模拟请求包含人物及开场、393 CSS px 无横向溢出均已通过。实际通过系统文档保存入口导出中文人物 JSON 并拉取核对 211 字节，第二次取消保存后无错误且操作恢复。

测试全部使用合成数据与模拟模型响应，没有上传真实用户聊天或调用收费模型。角色卡不是完整 SillyTavern 运行环境；没有验证厂商真机、真实模型记忆表现或云端 OCR 收费。Android 原生附件选择 URI 的既有验证限制仍见候选验收文档，人物导出使用本次实际完成的系统保存流程。

本地 release APK 为 19,738,949 字节，SHA-256 `5370fbaedf4d6691af37944586704aceadaf38c40625bc4066bfa72fd4f58354`；94 个文本资源检查无开发来源或合成测试数据。最终公开 APK 以本次 CI 固定产物独立核验为准。
